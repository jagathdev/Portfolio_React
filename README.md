# 💼 Developer Portfolio

A modern, responsive, and interactive developer portfolio built with React, TypeScript, and Vite to showcase professional experience, technical skills, projects, certifications, education, and contact information.

## 🚀 Live Demo

**Live Application:** https://portfolio-react-nine-wheat.vercel.app

## ✨ Features

* 🏠 **Hero Section** — Introduce yourself with an interactive and animated landing section.
* 👨‍💻 **About Section** — Present your professional profile and background.
* 🛠️ **Skills Section** — Showcase technical skills and technologies.
* 🚀 **Projects Section** — Display personal and professional projects.
* 💼 **Experience Section** — Highlight professional experience and career history.
* 📜 **Certificates Section** — Showcase certifications and achievements.
* 🎓 **Education Section** — Display academic background and qualifications.
* 📩 **Contact Section** — Provide a way for visitors to get in touch.
* 🌙 **Dark & Light Mode** — Switch between light and dark themes.
* ✨ **Smooth Animations** — Interactive animations and transitions throughout the portfolio.
* 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
* 🔗 **Smooth Scrolling** — Navigate between portfolio sections with smooth scrolling.
* 🔝 **Scroll to Top** — Quickly return to the top of the page.

## 🎨 Design

The portfolio uses a modern visual system based on:

* Light and dark themes
* Indigo and pink accent colors
* Glassmorphism effects
* Gradient text
* Smooth transitions
* Hover interactions
* Responsive layouts
* Modern typography

The project uses **Inter** for general text and **Outfit** for display headings, with primary colors based around indigo and secondary pink accents.

## ✨ Animations

The application uses multiple animation libraries to create an interactive experience.

### Framer Motion

Used for React-based animations and UI transitions.

### GSAP

Used for advanced animations and interactive visual effects.

### React Type Animation

Used for animated text and typing-style effects.

### Smooth Scrolling

React Scroll is used to provide smooth navigation between portfolio sections.

## 🌙 Dark Mode

The portfolio supports both light and dark themes.

The interface automatically applies different backgrounds, cards, text colors, borders, and interactive states depending on the selected theme.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/jagathdev/Portfolio_React.git

cd Portfolio_React
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm run dev
```

The application will start using Vite.

### 4. Build for Production

```bash
npm run build
```

### 5. Preview Production Build

```bash
npm run preview
```

### 6. Run ESLint

```bash
npm run lint
```

## 📦 Available Scripts
